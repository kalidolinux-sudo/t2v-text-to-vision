# T2V · Text to Vision

Describe a classifier in words, in any language, and get a working ResNet-20 whose 274,042 weights are
all generated from your text. An agent on **AMD TokenFactory** understands the request, describes each
class visually and reasons about lookalikes for classes it has never seen.

Code, results and paper trail: https://github.com/kalidolinux-sudo/t2v-text-to-vision
